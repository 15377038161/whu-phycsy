# Coze 同步说明：双层闯关、原理资料与操作拟合一体化

## 必须同步的学生流程

1. 首页继续使用现有实验卡片；首次进入时以无图片列表选择至少 3 个大实验，保存后首页只显示已选卡片，大关之间允许跳关。
2. 单实验工作台只保留“实验原理、预习测试、实验闯关、实验报告”四个页签，不再保留独立“操作”和“拟合”页签。
3. 演示视频、PDF 讲义、PPT/PPTX 课件统一放到实验原理页。PDF 可在线预览；PPT/PPTX 提供原文件下载并绑定同名 PDF 预览版。
4. 实验闯关使用左侧/顶部时间线加右侧单关页面，一次只显示一个小关；允许返回已完成关，未完成当前必做关时不能进入后续关。
5. 字段支持数值、短文本、单选、多选、数据表格和图片。服务器必须校验必填项、表格有效行、必传图片和拟合结果，禁止只靠前端勾选完成。
6. 拟合作为独立小关，明确引用前序步骤的数据表与横纵坐标列；进入实验闯关后后台预加载 Pyodide，不让学生重复录入数据。
7. 在线拟合失败时允许填写 Excel 拟合参数并上传结果图；在线结果与 Excel 兜底结果都同步到报告。
8. 上游数据修改后旧拟合结果自动失效。系统生成报告块如已被学生修改，先提示选择“刷新最新数据”或“保留手工修改”，禁止静默覆盖。
9. 全部必做小关完成后弹出“恭喜闯关成功”；正式提交报告后弹出对应奖状，首页直接展示已解锁证书。

## 统一步骤结构

```json
{
  "id": "collect_measurements",
  "title": "记录实验数据",
  "kind": "form",
  "text": "按照仪器读数记录实验数据。",
  "required": true,
  "fields": [
    {
      "key": "measurements",
      "label": "原始测量数据",
      "type": "table",
      "required": true,
      "min_rows": 2,
      "columns": [
        {"key": "frequency", "label": "驱动频率", "unit": "MHz"},
        {"key": "signal", "label": "信号强度", "unit": "a.u."}
      ]
    }
  ],
  "report_section": "raw_data"
}
```

拟合关必须配置：

```json
{
  "kind": "fit",
  "fit_config": {
    "source_step_id": "collect_measurements",
    "source_field_key": "measurements",
    "x_column": "frequency",
    "y_column": "signal",
    "template": "odmr",
    "required": true,
    "allow_excel_fallback": true
  }
}
```

## 接口契约

- `GET /student/level-selection`
- `POST /student/level-selection`
- `GET /student/experiment/<code>/progress`
- `PUT /student/experiment/<code>/steps/<step_no>`
- `POST /student/experiment/<code>/steps/<step_no>/image`
- `POST /student/experiment/<code>/steps/<step_no>/fit-result`
- `POST /student/experiment/<code>/steps/<step_no>/fit-fallback`

步骤保存返回 `current_step`、`validation_errors`、`report_sync_conflict`、`completed_steps` 和 `level_completed`。教师评分、自动准确度分和内部评语不得进入学生响应或报告。

## Coze 验收

- 原理页可见视频空状态/播放器、PDF 预览和 PPT 下载入口，实验闯关页不再出现大幅视频封面。
- 四个工作台页签、左侧时间线、单关页面、按钮文案、字体和颜色与本地一致。
- 空必填项返回 422，越级返回 409；保存当前关后只开放下一关。
- 前序数据无需复制即可进入拟合；在线拟合或 Excel 兜底均可完成拟合关并进入报告。
- 修改上游数据后旧拟合失效；报告手工修改不会被自动同步静默覆盖。
- 桌面与 390×844 手机尺寸均无页面级横向溢出；时间线可横向滚动。

本地基准验证：`python scripts/verify_project.py` 通过、`pytest -q` 为 80 passed、`node --check static/platform.js` 通过。

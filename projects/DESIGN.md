# DESIGN.md

本次同步（关卡自由挑战、通关纪念证书、自动准确度评分）的设计思考。项目已有完整的「量子·樱珞」学术纪念风格（详见 `UI_VISUAL_STANDARD.md`），本文档只描述本次改动的风格判断与落地约束，不另起新风格。

## 气质与意象

- **首页是"关卡长廊"，不是商品橱窗**：五台实验像五座依次点亮的实验台，学生走进来第一眼看到的是"第 N 关"的秩序感和每一关的可挑战性，而不是促销式的"立即开始"。
- **证书是纪念，不是奖状**：弹窗文案始终是"实验通关纪念证书"，底部必须注明"本证书仅作为学习纪念，不代表教师审核通过"。它的气质是实验室里贴在小黑板上的手写纪念卡，不是烫金奖状。
- **教师端的自动评分是参谋，不是裁判**：准确度评分放在"自动准确度评分"侧卡里，措辞为"建议分/参考"，不与人工评分并列争夺权威。

## 视觉策略

- 关卡卡片沿用 `.experiment-display-card` 横向画廊骨架：顶部实景照片压暗 + 白色 `第 N 关` 序号，左下状态徽章（可挑战=蓝、已通关=金），正文卡内一行摘要、一行预习题成绩、一个主按钮。
- 通关纪念区沿用 `.award-shelf` 樱花木质展柜：左侧 `sakura-certificate` 证书原件，右侧 `.award-medal` 纪念牌横排；未通关关数置灰加锁。
- 证书弹窗复用 `.sakura-certificate` 证书纸张，居中、可关闭，不做全屏遮罩动画轰炸。

## 配色方案

沿用既有变量，不新增主色：
- 关卡序号与可挑战状态：`--blue` 系（珞珈深蓝），来自深夜实验室的黑板。
- 已通关状态与纪念：`--gold`/金棕，来自老樱花木展柜。
- 教师端自动评分卡：`--jade-soft` 底 + `--jade` 数字，传达"客观计算、冷静参考"。

## 字体排版

本次同步后的字号体系（与 `UI_VISUAL_STANDARD.md` 一致，落在 CSS 变量）：
- H1 = 42px、H2 = 26px、H3 = 20px；正文与按钮/输入控件 = 14px（移动端正文同样 14px）。
- 关卡卡片标题走 H3 衬线显示体；`第 N 关` 序号用小字距大写字重压在照片上；指标数字用 Inter 等宽数字。
- 学生首页用更宽的内容容器，让五关卡片横向排开不拥挤。

## 动效与交互

- 提交成功回首页后证书弹窗自动打开：淡入即止，不做弹跳；关闭途径齐全（右上角 ×、遮罩空白处点击、Esc），焦点进入弹窗后落在关闭按钮，关闭后归还触发位置。
- 关卡卡片 hover 轻抬 + 照片微缩放（沿用既有 transform 规格）。
- 纪念牌 hover 上浮，未解锁保持置灰，不给假希望动效。

## 设计禁忌

- 不出现"机器判定/自动通过/自动评分"字样在学生端任何页面与 API。
- 不新增"进入荣誉展厅"式的唯一跳转入口；首页直接内嵌"我的通关纪念"，荣誉展厅页保留但不作为唯一出口。
- 不把证书与"审核通过"绑定；不出现红色警示式证书文案。
- 不给学生展示教师评分默认值来源之外的教师端数据。

# 珞珈量子实验馆

武汉大学自托管量子实验教学平台。技术栈保持简单：Flask、Jinja、原生 JavaScript、PostgreSQL、浏览器 Pyodide。

## 五项实验

- 离子阱实验
- 量子密钥分发
- 量子纠缠
- 金刚石量子计算机
- 单像素光子成像

这五项是平台核心正式实验。教师通过“新建实验草稿”增加的教学模块在完成内容、题库和步骤并发布后，会自动进入学生实验目录；学生首页的卡片编号和无专属图片时的校园封面均由已发布目录动态生成。学生首次进入时在集中式选关弹窗中查看全部关卡，保存后首页只展示已选关卡。

教师可在“实验管理”中使用上移、下移按钮调整整个实验目录；顺序保存到数据库后，学生端实验展厅、实验编号和下一实验推荐同步使用新顺序。教师目录固定为不含图片的纯文本列表，每条实验集中提供编辑、复制、发布、下架和安全删除；页面不展示历史版本时间线。复制实验会创建新的独立实验草稿，不覆盖原实验。

学生首页主视觉是个人“当前实验”：优先显示最近发生预习或报告提交操作的实验，没有活动记录时显示目录第一项。选择依据只使用冻结预习和提交修订，不读取教师评分或审核结果。

## 本地开发

```powershell
python -m pip install -r requirements.txt
python app.py
```

未设置 `DATABASE_URL` 时开发环境使用 `runtime/platform.db`。生产环境必须使用 PostgreSQL。默认演示账号为教师 `admin/admin123`、学生 `S001/123456`。

## UI V6

视觉素材统一放在 `static/images/brand/` 与 `static/images/experiments/`：品牌标识采用武汉大学官网标准文件，五项实验使用对应设备/光路主视觉，`whu-quantum-linescape.png` 是全站共用的珞珈建筑与量子轨迹纹样。学生端和教师端通过同一个固定视口背景层以 `cover` 等比铺满，禁止纵向重复，因此短页、长页和不同宽高比屏幕都不会在下半部分出现空白；两端页眉也共用同一品牌组合、布局和响应式交互，仅导航业务文字不同。每页最多出现一幅完整校园线景，教师主视觉使用完整图，后续留白只保留低透明度局部山线与轨迹，避免上下重复同一建筑群；信息卡保持高对比纸张底色。登录页和学生端使用清晰可见的分层樱花飘落，教师端混合樱花粉与克制金色花瓣。校园照片本体不做裁剪旋转，避免屋檐等建筑细节因动效错位；仅独立柔光与花瓣层参与动画，全部自动遵循系统减少动态效果设置。

唯一界面位于 `templates/`、`static/quantum-platform.css` 和 `static/platform.js`。学生端包含实验探索、我的实验、报告与荣誉；教师端包含审核、实验管理、学生管理。实验工作台按实验原理、预习测试、实验闯关、实验报告四区切换。操作与拟合合并为一次只显示一个小关卡的页面式流程，原始数据由结构化步骤字段录入，拟合小关自动读取前序数据；教师预设代码只在浏览器 Pyodide 中生成拟合结果。

报告区是结构化类 Word 编辑器：支持中英文题名与摘要、段落格式、列表、公式、图片、图注和表格，右侧同步显示 A4 论文版式。活动草稿按学生、课程和实验版本保存在服务器并自动保存；两个页面同时编辑时使用乐观锁阻止静默覆盖，失败内容会保留为浏览器恢复副本。正式提交从服务器草稿创建不可变修订，历史报告只能“复制为新修订”后继续编辑。网页报告、DOCX 和 PDF 读取同一结构化文档；PDF 精确预览与最终导出均使用本地 `simhei.ttf`，不执行学生内容或任意 HTML。

学生首页保留原有实验卡片样式，但首次进入会自动打开选关弹窗；弹窗使用不含图片和关卡编号的纵向列表，仅展示实验名称与简介。完成至少 3 关选择后，首页只展示已选卡片，支持“调整关卡”重新打开弹窗。首页首项统计“已完成实验”只计算当前最新且未撤回的正式提交，不以预习完成数或教师评分代替。

教师端按班级和实验分工：学生管理用于创建班级、导入名单、查看进度与重置密码；实验管理使用纯文本列表维护实验，条目级操作统一为编辑、复制、发布、下架和安全删除。实验编辑器按六个内容步骤组织，并提供返回实验管理、上一步和下一步；题库不暴露 JSON，改为左侧题目总览、右侧逐题审核表单，支持手动新增/删除、AI 按数量补题和整库重建。学生名单支持 `.xlsx/.xls`，表头前可有标题或说明，学号和姓名可位于任意列；系统会结合表头和数据特征自动识别，忽略班级、专业、手机号等额外字段，无法安全识别时整批拒绝。Excel 没有密码列时可在导入窗口填写统一临时密码，新账号首次登录仍必须改密。AI 实验创建可直接输入或使用 Chrome/Edge 语音转写，也可上传 PDF、DOCX、TXT、Markdown 实验材料；系统生成实验代码、名称、简介、原理、仪器、拟合口径与至少 5 条详细操作步骤。教师确认后只创建可编辑实验草稿，不直接发布。材料最大 20 MB，扫描版 PDF 需先 OCR，旧版 DOC 需另存为 DOCX；AI 或材料解析失败时不会创建占位实验。

教师“实验学情观测台”由班级整体进度、实验任务完成率、学生个体明细三部分组成，支持按班级、实验、任务、状态与日期筛选。页面汇总预习分、教师人工分、最近活动和完成状态，对未完成且连续 7 日无新活动的学生标记停滞预警，并直接列出进度最慢的 3 名学生供下钻定位；当前筛选结果可导出为包含三个工作表的 `.xlsx` 学情报表。页面每 30 秒自动刷新，也可手动立即刷新。

教师端品牌头使用项目内置的武汉大学标准组合，不热链外部图片；审核台复用官网的武大蓝、金色细线、数字锚点与 `1893` 识别元素。待审核修订在桌面端突出显示，审核与学生名单表格在窄屏自动转换为带字段标签的卡片，不依赖横向拖动才能识别关键内容。

全平台字体、标题层级、正文、辅助文字、控件文字、图标尺寸和页面宽度统一遵循 `UI_VISUAL_STANDARD.md`；教师端业务架构与专用响应式规则见 `TEACHER_UI_SPEC.md`。审核队列与学情观测使用完全一致的标题、二级导航和内容边界；学生管理只保留名单和账号操作，完成率、未完成名单与停滞预警统一由学情观测台承接。手机端学情筛选默认折叠，实验目录固定卡片视图；内部报告将评分面板置于正文之前，并提供评分/正文快捷锚点。

学生登录后的所有页面右下角均提供受限“珞珈 AI 助教”入口。助手只解释当前实验已发布原理，或提醒已发布操作步骤；回答使用端到端流式输出，模型生成一段浏览器就立即显示一段，并在连接中断时保留已生成内容。服务端不接收整页页面文本，也不会读取或指导具体实验数据和拟合。成绩、评分、排名、其他学生信息、预习题答案、题库、原始/具体数据、标准值、参考结果和拟合参数会在调用模型前直接拒绝。教师页面、教师评分和内部评语不进入答疑上下文，服务不可用时会明确提示。

AI 答复先经过 HTML 转义，再仅渲染受控的 Markdown 加粗、列表和 KaTeX 行内/行间公式；LaTeX 解析失败或公式组件不可用时显示安全的公式源码，不执行 AI 返回的 HTML。

预习题库按 10 个母题方向组织，每个方向至少提供不同考法，标准 AI 题库为“10 个母题 × 每题 4 个变式”。每名学生得到独立的十题组合，题目和选项顺序也独立随机；提交后题卷冻结并逐题显示回答对错、正确答案和解析。学生重做时完整保留上一套历史，排除做过的全部原题，再按相同考点换题；变式耗尽时拒绝复用并提示教师扩充。AI 生成的四个选项必须处于同一实验语义范围；系统会拒绝无关干扰项、重复题目、猜题式选项、过短解析和母题结构不合格的整批题库。内置题库质量修订通过新发布版本生效，不覆盖历史版本。

报告提交时，系统根据发布版本冻结的参考值自动计算数据误差和准确度建议分：误差≤5% 为 100 分，≤7% 为 90 分，≤10% 为 85 分，≤15% 为 80 分，其余为 70 分。该规则为确定性数值计算，不调用大模型；只在教师内部审核页显示，并作为人工最终成绩的默认值。学生端唯一展示的分数仍是学生自己的预习题百分制成绩，十道题每答对一题计 10 分，并提供逐题解析。教师在内部审核页填写 0–100 分、审核决定和内部评语，最新有效人工审核是唯一正式实验成绩；教师审核台可按负责班级一键导出 Excel。教师成绩、审核结果、自动准确度分、通过状态和内部评语不会进入学生 API、学生网页或学生报告。学生首页另设不含成绩的“学习纪念”：每个实验在学生正式提交对应报告后解锁浅色樱花纪念证书，撤回报告后重新锁定；该功能不读取教师审核或评分。

教师可在实验草稿中选择性上传 JPG、PNG 或 WebP 展厅封面，以及 MP4、WebM、MOV 或 M4V 原理演示。PDF 可在原理页直接预览；PPT/PPTX 保留原文件下载，并可绑定同名 PDF 预览版。封面、视频、原文件与预览关系均随发布版本冻结，默认单次上传上限为 500 MB，可通过 `MAX_UPLOAD_MB` 调整。教师发布按钮会先保存当前表单再发布，也可删除尚未发布的草稿。已发布版本不能物理删除，但可“下架”；历史提交、审核和报告继续绑定原版本。

学生端“实验闯关”展示当前发布版本的完整文字流程和真实服务器进度。字段支持数值、短文本、单选、多选、数据表与图片；空必填项、数据行不足、拟合未完成或越级操作都会被服务器拒绝。核心五项实验通过新发布版本升级，旧提交继续绑定旧版本。

学生端公式使用项目内置 KaTeX 静态资源渲染，不依赖外部 CDN；教师端不加载该资源。AI 答疑中的行内公式与块级公式分别支持 `$...$`、`\\(...\\)`、`$$...$$` 和 `\\[...\\]`。

进入实验闯关页后会在浏览器后台预热 Pyodide，并预装 NumPy、SciPy、Matplotlib 与 Pandas；拟合小关直接读取前序数据表。自定义代码会先通过 `loadPackagesFromImports` 加载可用模块，缺失模块会显示具体名称。在线拟合不可用时，学生可填写 Excel 拟合参数并上传结果图，两种结果都同步至报告。生产环境建议通过 `PYODIDE_BASE_URL` 指向校内静态镜像。

## 双层实验闯关

学生进入首页后先选择班级要求数量的大实验关卡（默认至少 3 关），大关之间可以跳关。单实验内部按顺序完成页面式小关卡，允许返回已完成关复查。步骤数据、图片、在线拟合或 Excel 兜底结果会保存并同步进入结构化报告；修改上游数据会使旧拟合失效。全部必做步骤完成后显示闯关成功提示，正式提交报告后解锁对应学习纪念证书。

# 教师端 UI V7 设计与开发交底

全平台字体、标题层级、正文、辅助文字和图标尺寸以 `UI_VISUAL_STANDARD.md` 为唯一标准；本文件只补充教师端信息架构、数字和业务响应式规则。

## 1. 信息架构

教师端只保留三个一级入口：`审核`、`实验管理`、`学生管理`。审核工作区内部用二级导航切换“审核队列 / 学情观测”。

| 页面 | 唯一职责 | 本轮去重结果 |
| --- | --- | --- |
| 审核队列 | 查找待审核修订、进入人工评分、导出成绩 | 删除主视觉重复课程/待审核摘要和重复控制侧栏 |
| 学情观测 | 班级概览、实验完成率、学生明细、预警、导出 | 统一承接完成率与预警；新增全部/未完成/预警快速筛选 |
| 实验管理 | 实验内容与发布状态维护 | 固定纯文本列表；每条提供编辑、复制、发布、下架、删除，不展示历史版本 |
| 学生管理 | 班级切换、名单导入、账号与密码 | 删除重复统计卡和重复操作侧栏；进度分析跳转观测台 |

## 2. 视觉令牌

- 布局基准：8 px 网格；页面主间距 24 px；卡片圆角 12 px。
- 页面宽度：审核队列与学情观测等教师工作台桌面最大 1328 px；平板左右留白 18 px；手机左右留白 10 px。
- 数字：统一使用 `--ui-font-number`，等宽数字 `tabular-nums`，字重 700，字距 `-0.02em`。主指标桌面 28 px、手机 24 px；表格数字跟随正文层级。
- 标题、正文、控件和图标：直接使用全平台 `--ui-*` 令牌，不再维护教师端独立字号。
- 色彩：主操作武大蓝，正常/完成使用玉石青，提醒与预警使用克制金色；红色只用于不可逆或失败状态。
- 控件：桌面最小高度 44 px，手机关键按钮与输入最小高度 48 px；所有可交互元素必须有文字或可访问名称。

## 3. 栅格与对齐

- 页面、卡片、表格均从同一内容边界起排；卡片内部使用 16/24 px 间距。
- 表格桌面行高 48 px，数字垂直居中；窄屏改为字段名/字段值双列卡片，不依赖横向滚动。
- 页面标题的说明、状态和操作在桌面横向对齐；手机按“标题 → 状态 → 操作”顺序纵向排列。
- 学情筛选桌面常驻；小屏默认折叠为“筛选”按钮，展开后单列显示。

## 4. 响应式行为

- `> 900 px`：完整桌面布局。
- `681–900 px`：复杂双栏合并为单栏，保留完整业务信息。
- `≤ 680 px`：表格转字段卡片；实验文本列表转为单列操作卡片；筛选折叠；触控控件放大。
- 教师报告审核在手机端把评分面板置于报告正文之前，并提供“评分审核 / 报告正文”粘性快捷导航；长英文标题和表格允许安全换行或局部滚动。

## 5. 核心移动流程

1. 审核：审核队列 → 打开报告 → 顶部直接评分/选择决定/填写评语 → 保存。
2. 未完成名单：学情观测 → 展开筛选并选择班级/实验 → 点击“未完成” → 搜索学生。
3. 进度追踪：班级整体指标 → 点击最慢学生 → 自动定位该生明细；预警卡片使用金色强调。

## 6. 前端实现契约

- 全局数字类名：`.teacher-number`。
- 学情移动筛选：`[data-analytics-filter-toggle]` 控制 `[data-analytics-filters]`。
- 学生状态筛选：`[data-student-status-filter]` 与行属性 `data-student-incomplete`、`data-student-warning`。
- 移动表格：每个 `td` 必须提供 `data-label`。
- 报告锚点：`#teacherReviewPanel` 与 `#reportContent`。
- 实验题库：`[data-question-manager]` 内左侧 `[data-question-list]` 为总览，右侧 `[data-question-form]` 为逐题审核；`questions_json` 仅作为隐藏保存协议，不得向教师显示源码编辑器。
- 题库生成：`mode=append` 单次允许新增 1–20 道且不得覆盖原题；`mode=replace` 明确提示后整库重建 40 道。AI 生成题默认待审核，教师保存单题后标记为已审核。
- 实验草稿页头与操作侧栏统一使用浅色纸张表面；武大蓝用于标题和主操作、玉石青用于 AI/完成状态、红色仅用于删除。
- 所有视觉规则继续集中在 `static/quantum-platform.css`，不得新增平行样式文件。

## 7. 验收清单

- 1440×900、1024×768、390×844 下无页面级横向溢出或元素遮挡。
- 手机端无需滚过报告正文即可开始评分；输入框不会触发异常缩放。
- 30 秒内可找到班级完成率及最慢 3 名学生；未完成/预警筛选与姓名学号搜索可组合使用。
- 数字字体、字重、对齐一致；桌面表格与手机字段卡片含义完整。
- 审核、导出、班级管理、实验管理的唯一入口边界清晰，无重复控制板块。
- 题库页面不得出现 JSON 或代码编辑器；桌面为题目总览/审核表单双栏，手机为横向题目列表/纵向审核表单，页面无横向溢出且关键按钮不低于 48 px。

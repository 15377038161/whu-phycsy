# Coze 同步说明：学生通关、荣誉展示与自动评分

## 同步目标

本轮调整把学生首页从“仅浏览实验展厅”改为可直观看到并任选的实验通关入口；每完成一项实验即视为通关一关，并在首页直接展示对应的学习纪念。与此同时，教师审核侧增加基于实验参考值的自动准确度评分。

请 Coze 侧按下述业务行为同步，不要保留旧的平行入口或旧版评分逻辑。

## 1. 学生首页：任选实验关卡

### 目标行为

- 首页动态展示课程中全部已发布、未下架的实验；当前默认有 5 项，未来教师新增实验后应自动增加，不能写死为 3 项或 5 项。
- 每张实验卡必须同时展示：`第 N 关`、`可挑战/已通关`、实验名称、简要说明和主按钮。
- 标题和说明明确表达：`选择一关开始实验`、`无需按顺序，任选一关即可开始挑战`。
- 未完成实验的主按钮为 `选择本关并开始`；已完成实验显示 `查看本关记录`。
- “已完成实验”只统计该学生每个实验最新且状态为 `submitted` 的正式报告修订；预习完成不能算通关，撤回后不再算通关。

### 当前实现位置

- 页面：`templates/student_home.html`
- 首页数据与完成数：`platform_app/blueprints/student.py` 的 `home()`
- 连续横向实验展廊与卡片样式：`static/quantum-platform.css`

### Coze 侧实现要点

1. 从后端发布实验列表读取关卡，而非使用静态数组。
2. 以实验排序字段决定第 N 关的顺序。
3. 不要求先完成上一关；学生可从任意已发布实验进入。
4. 只在正式报告成功提交后更新本关状态与首页完成数。

## 2. 通关证书与首页荣誉展示

### 目标行为

- 学生完成预习、实验、拟合并正式提交报告后，回到首页自动弹出该实验的“实验通关纪念证书”。
- 弹窗支持关闭按钮、遮罩关闭、Escape 关闭和焦点控制；关闭后仍停留在首页继续选择下一关。
- 首页底部直接展示“我的通关纪念”：左侧为当前证书，右侧为全部实验纪念牌；不再设置“进入荣誉展厅”作为唯一入口。
- 未完成的纪念牌保持锁定态；完成对应正式报告后解锁；撤回该报告后重新锁定。
- 证书只是学习纪念，不表示教师审核通过，也不按成绩授予。

### 解锁边界（必须保持）

- 仅依据学生该实验最新有效 `submitted` 正式报告修订。
- 禁止依据教师审核结论、教师人工分、自动准确度分、历史 Award 或“通过”状态解锁。
- 学生端不能看到教师评分、审核决定和内部评语。

### 当前实现位置

- 提交后携带证书参数回首页：`platform_app/blueprints/student.py` 的 `submit_experiment()`。
- 首页证书弹窗和关卡卡片：`templates/student_home.html`。
- 首页直接嵌入的证书/纪念牌组件：`templates/_learning_memorial.html`。
- 自动打开证书弹窗：`static/platform.js` 的 `setupAutoOpenModal()`。
- 荣誉解锁与纪念牌交互：`static/platform.js` 的 `setupAchievements()`。

## 3. 自动准确度评分（仅教师端）

### 规则

提交报告时，根据该发布实验版本冻结的 `reference_value` 与学生提交的 `result_value` 计算相对误差：

`误差百分比 = |学生结果 - 参考值| / |参考值| × 100`

| 误差范围 | 自动准确度建议分 |
| --- | ---: |
| ≤ 5% | 100 |
| ≤ 7% | 90 |
| ≤ 10% | 85 |
| ≤ 15% | 80 |
| > 15% | 70 |

### 目标行为

- 该分数使用确定性数学计算，不调用大模型，以保证同一数据每次结果一致。
- 自动保存本次修订的 `relative_error` 和 `deterministic_score`；报告修订不可原地覆盖。
- 教师审核页显示自动准确度分和误差百分比，并把自动分作为人工最终分的默认值。
- 教师仍可修改最终人工分；正式成绩仍以最新有效人工审核分为准。
- 自动准确度分、误差百分比、教师最终分、审核结论和内部评语均不得进入学生 API、学生页面或学生报告。

### 当前实现位置

- 评分函数与提交时写入：`platform_app/services/submissions.py` 的 `accuracy_grade()` 和 `submit()`。
- 教师审核页展示与预填：`templates/report.html`。
- 教师端样式：`static/quantum-platform.css` 的 `.automatic-accuracy-score`。

## 6. 不应同步的内容

- 不要把本地预览地址、演示账号、数据库文件或环境变量写入 Coze 配置。
- 不要将自动准确度分暴露给学生。
- 不要用“审核通过”或成绩条件解锁学生证书。
- 不要恢复旧的“荣誉展厅仅跳转入口”；首页应直接呈现证书和纪念牌。

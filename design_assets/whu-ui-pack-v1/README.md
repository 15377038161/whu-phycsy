# 武汉大学珞珈量子 UI 素材包 v1

本素材包以教师确认的“珞珈建筑 × 量子轨迹”画面为唯一母版，统一采用暖白纸张、武大蓝、玉石青、克制金色与少量樱花粉。画面中的建筑为原创概念性校园建筑，不替代武汉大学官方校徽、校名标准字或真实校园照片。

## 目录

- `source-png/`：生成原稿，适合二次裁切与设计留档。
- `webp/`：质量 88 的网页优化版，优先用于实际页面。
- `official-brand/`：项目现有的武汉大学校徽与标准组合，非 AI 生成。
- `preview/whu-ui-pack-overview.jpg`：六项素材总览。
- `manifest.json`：用途、尺寸、焦点与 SHA-256。
- `tokens.css`：色彩令牌、桌面/移动端主视觉和卡片背景示例。
- `PROMPTS.md`：本次生成提示词摘要与共同约束。

## 素材用途

1. `01-teacher-hero-desktop`：教师审核台桌面主视觉；文字放左侧，建筑保持右侧。
2. `02-teacher-hero-mobile`：移动端主视觉；标题位于上半区，建筑从右下方进入。
3. `03-section-linescape`：内容分隔、页脚或长页面留白；建议使用 18%–45% 不透明度。
4. `04-review-card`：审核队列、报告归档、提交修订功能卡。
5. `05-experiment-card`：实验管理、版本生命周期、设备与光路功能卡。
6. `06-analytics-card`：学情观测、任务路径、学生进度功能卡。

## 使用规则

- 校徽和“武汉大学”标准字使用 `official-brand/` 中的项目现有官方资源，在 HTML 中独立叠加，不要烧录进生成背景。
- 主视觉最多在同一页面完整出现一次；其他区域优先使用线景或局部功能卡。
- 文字区应加暖白或武大蓝遮罩，保证正文对比度不低于 WCAG AA。
- 不旋转、镜像或做建筑本体位移动画；允许独立的樱花、柔光和量子轨迹层做轻微动画。
- 桌面主视觉推荐 `background-position: center right`；移动端使用独立移动图，不直接裁切桌面图。
- 功能卡图片建议叠加 68%–88% 暖白遮罩，避免与按钮、表格竞争注意力。

## 快速接入

将 `webp/` 中选定素材复制到项目 `static/images/`，再参考 `tokens.css`。当前素材包没有自动替换正式页面，便于教师先审阅后再决定接入范围。
